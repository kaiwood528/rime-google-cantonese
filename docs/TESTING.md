# 全新電腦測試清單

用來驗證「從未裝過小狼毫的電腦」能否只靠 `setup.cmd` 裝好並正常使用。每完成一次，把結果填入最後的紀錄表。

## 測試環境

| 環境 | 測到甚麼 | 備註 |
|---|---|---|
| 虛擬機（VirtualBox／VMware Workstation＋Windows 11 安裝檔） | 全部，可用快照反覆回到全新狀態 | 需約 64 GB 磁碟、4–8 GB 記憶體；未啟用的 Windows 足夠測試 |
| 朋友的電腦（未裝過小狼毫） | 全部，最接近真實用家 | 同時當作第四階段的試裝 |
| 同一部電腦的新 Windows 用戶 | 只測到用戶層面（插件、背景程式、問答） | 小狼毫已在全機安裝，測不到自動安裝小狼毫；若小狼毫附帶的資料已有粵語方案，亦測不到自動下載方案 |

## 準備

1. 確認未安裝小狼毫：「設定 → 應用程式」找不到 Weasel／小狼毫。
2. 取得本專案 ZIP（GitHub 頁面 → Code → Download ZIP；私人倉庫期間由維護者直接提供 ZIP）。
3. 解壓到任何資料夾，例如「下載」。

## 步驟及預期結果

| # | 步驟 | 預期結果 |
|---|---|---|
| 1 | 雙擊 `setup.cmd` | 可能出現「檔案來自互聯網」警告，按「執行」後出現安裝程式標題 |
| 2 | 「找不到小狼毫」→ 按 Enter（Y） | winget 下載並安裝小狼毫（會彈出管理員權限提示）；之後顯示小狼毫版本 |
| 3 | 「找不到粵語拼音方案」→ 按 Enter（Y） | 約 20 秒內顯示 `installed rime/rime-cantonese (12 files)` 等行 |
| 4 | 拼音方案輸入 1、2、`jat` 或 `yat`；用法選 1、2 或 3 | 顯示「正在安裝」，最後顯示「安裝完成」和用法提示 |
| 5 | 如果工作列的語言列沒有小狼毫，登出再登入一次 | 按 `Win`＋空白鍵可以切換到小狼毫 |
| 6 | 打開記事本，切換到小狼毫，打 `jat`（耶魯打 `yat`） | 候選有「日」；方案名稱是「粵語拼音」或「粵語拼音（耶魯）」 |
| 7 | 打 `ngodeigamjat`，連按兩下左 Shift | 約 0.3 秒後最前面出現 ☁ 候選「我哋今日」之類 |
| 8 | 用法 1：輸入任何拼音後稍作停頓 | 每頁 6 個候選，第 6 個帶 ☁ |
| 9 | 用法 3：輸入一句後稍作停頓 | 候選只剩 ☁ 候選；連按兩下左 Shift 變回小狼毫候選 |
| 10 | 用法 2：打字但不按雙 Shift，然後打開 `%APPDATA%\Rime\gcloud\request.txt` | 第一行是空的（沒有送出拼音）；按過雙 Shift 後才會出現當時的拼音 |
| 11 | 重新開機後再打字 | 背景程式自動啟動，雙 Shift 仍然有 ☁ 候選 |
| 12 | 雙擊 `diagnose.cmd` | 桌面出現 `rime-google-cantonese-report.txt`，「Background program」部分 `running: True`，Google test 有候選 |
| 13 | 雙擊 `uninstall.cmd` | 顯示「已移除」；小狼毫仍可打粵語，但不再有 ☁ 候選；`%LOCALAPPDATA%\Programs\rime-google-cantonese` 已刪除 |

任何一步不符合預期：先雙擊 `diagnose.cmd`，把桌面的報告連同步驟編號、畫面截圖一併回報。

## 要額外留意

- 小狼毫版本：winget 目前提供 0.17.x，本插件原本只在 0.15.0 測試過，所以第 6–9 步最重要。
- 防毒軟件有沒有攔截 `rime-gcloud.exe`（它會模擬按下 `F24` 鍵）。
- 安裝程式有沒有出現紅色錯誤訊息；有的話請截圖。
